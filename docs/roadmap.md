# Roadmap

## Sprint 1

- поднять BotFather token и Supabase проект;
- реализовать `/start`;
- включать подписку автоматически при `/start`;
- реализовать выбор города;
- реализовать выбор сетей;
- сохранить подписку в БД.

Статус: каркас этого этапа уже реализован.

## Sprint 2

- сделать adapter для `Kaufland`;
- сделать adapter для `PENNY`;
- отправлять ежедневную сводку по расписанию.

## Sprint 3

- включить ежедневный cron;
- добавить retries и логирование;
- ограничить повторные сообщения;
- сохранить историю отправок.

## Sprint 4

- добавить новые сети;
- добавить фильтры категорий;
- добавить админ-алерты при падении adapter.
